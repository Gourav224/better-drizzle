`0.2.0` ships as **one package**: the official plugins move from scoped `@better-drizzle/*` packages to subpath exports of `better-drizzle`. It also adds relation reads and writes, cursor pagination, row locks, `.explain()`, and the `rules`, `eslint`, and `zod` plugins.

> [!IMPORTANT]
> Breaking change for plugin imports. Follow [Upgrading to 0.2](https://better-drizzle.com/docs/guides/upgrading#upgrading-to-02) before you bump.

### Breaking changes

- **One package, plugin subpaths.** Import plugins from `better-drizzle/rules`, `better-drizzle/zod`, `better-drizzle/soft-delete`, `better-drizzle/timestamps`, and `better-drizzle/eslint`. The scoped `@better-drizzle/*` packages are discontinued. `better-drizzle/plugins` is the new plugin authoring entry point. Every entry point ships ESM, CommonJS, and declarations. ([`0858c46`](https://github.com/almeidazs/better-drizzle/commit/0858c46), [`a066b56`](https://github.com/almeidazs/better-drizzle/commit/a066b56))

### Features

- **Relation reads.** Nested `include` and `select` with `where`, `orderBy`, `take`, `skip`, and `cursor` at any depth, loaded by a batched loader (one query per relation node). ([`42184d3`](https://github.com/almeidazs/better-drizzle/commit/42184d3))
- **Relation writes.** `connect` on create, and `connect`, `disconnect`, and `set` on update, in an implicit transaction. ([`42184d3`](https://github.com/almeidazs/better-drizzle/commit/42184d3), [`64964a5`](https://github.com/almeidazs/better-drizzle/commit/64964a5))
- **Many-to-many.** Simple junction tables are inferred. ([`5942400`](https://github.com/almeidazs/better-drizzle/commit/5942400))
- **`include._count`.** Relation totals as correlated subqueries, without extra round trips. ([`997f471`](https://github.com/almeidazs/better-drizzle/commit/997f471))
- **`cursor()` pagination.** `before` / `after` cursors with `hasNext` and `hasPrevious`; `paginate()` stays offset-based. ([`37b6c8d`](https://github.com/almeidazs/better-drizzle/commit/37b6c8d))
- **Row locks.** `lock` on reads for PostgreSQL and MySQL, with `skipLocked`, `noWait`, and `locks.transactionsOnly`. ([`b64c100`](https://github.com/almeidazs/better-drizzle/commit/b64c100))
- **`.explain()`.** Every read returns a lazy thenable with a cross-dialect `.explain()`; relation stages are reported as deferred. ([`5c451f9`](https://github.com/almeidazs/better-drizzle/commit/5c451f9), [`ce0e3e4`](https://github.com/almeidazs/better-drizzle/commit/ce0e3e4))
- **`extends()`.** Client-level helpers that survive `$withContext()` and transaction clients. ([`290e1cb`](https://github.com/almeidazs/better-drizzle/commit/290e1cb))
- **PostgreSQL JSONB filters.** Typed path filters on JSONB columns. ([`7dd1cf9`](https://github.com/almeidazs/better-drizzle/commit/7dd1cf9))
- **`better-drizzle/rules`.** Runtime guardrails (for example, writes without `where`). ([`c7ae257`](https://github.com/almeidazs/better-drizzle/commit/c7ae257))
- **`better-drizzle/eslint`.** The statically checkable rules as an ESLint plugin. ([`2c0fe7b`](https://github.com/almeidazs/better-drizzle/commit/2c0fe7b))
- **`better-drizzle/zod`.** Generated Zod schemas on `db.<table>.$zod` and opt-out runtime validation. ([`28822b0`](https://github.com/almeidazs/better-drizzle/commit/28822b0))
- **Agent skill.** A first-party skill pack for AI coding agents. ([`cca8f2e`](https://github.com/almeidazs/better-drizzle/commit/cca8f2e))
