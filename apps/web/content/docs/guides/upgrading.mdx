Check the installed version in `package.json`, then follow every guide between it and the latest release, in order. The [changelog](/changelog) lists every change per release.

| You are on | Follow | What changes |
| --- | --- | --- |
| `0.1.x` (scoped `@better-drizzle/*` packages) | [Upgrade to 0.2](/docs/guides/upgrading-0-2) | Import specifiers only |
| `0.2.x` (Drizzle 0.x) | [Upgrade to 0.3](/docs/guides/upgrading-0-3), then [Changes in 0.3](/docs/guides/upgrading-0-3-changes) | Drizzle ORM 1.x, `defineRelations`, `better(db)` without `schema`, stricter types |
| `0.3.x` | [Upgrade to 0.4](/docs/guides/upgrading-0-4), then the [changelog](/changelog) | `_count` is renamed to `count`; review the behavior changes listed per release |

<Callout type="info" title="Staying on drizzle-orm 0.x">
	The `0.2.x` line is the last one that works with `drizzle-orm` 0.x (peer
	`^0.30.0`). Pin `better-drizzle@~0.2.0` until you upgrade Drizzle itself.
	No release supports both major versions of Drizzle.
</Callout>

## Versioning

The package has a single version line: `better-drizzle` and every plugin entrypoint report the same `version`:

```ts
import { version } from 'better-drizzle';
import { version as zodVersion } from 'better-drizzle/zod';

version === zodVersion; // true
```

See [stability & semver](/docs/reference/stability) for what each release line guarantees.
