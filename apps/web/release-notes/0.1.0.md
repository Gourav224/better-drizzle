First public release of better-drizzle: a repository-style API on top of an existing Drizzle client, for PostgreSQL, MySQL, and SQLite.

### Highlights

- **Table delegates.** `findMany`, `findFirst`, `findUnique`, `create`, `createMany`, `update`, `updateMany`, `delete`, `deleteMany`, `upsert`, `count`, `exists`, `paginate`, and `repository(name)` lookup.
- **Duplicate handling.** `create` and `createMany` accept `skipDuplicates` (`true` or a list of columns). ([#10](https://github.com/almeidazs/better-drizzle/pull/10))
- **`upsertMany`.** Native-first batch upsert with conflict targets, update strategies, chunking, and optional `select`. It fails fast on unsupported dialects instead of falling back to per-row loops. ([#11](https://github.com/almeidazs/better-drizzle/pull/11))
- **Transactions.** Nested savepoints, retries, explicit rollback, `afterCommit`, and `afterRollback`.
- **Raw SQL.** Safe `$raw` and `$executeRaw` with tagged templates, plus `$rawUnsafe` behind an explicit option.
- **Plugins.** Typed `operationArgs`, transforms, hooks, client extensions, and model extensions. ([#1](https://github.com/almeidazs/better-drizzle/pull/1))
- **Errors.** `BetterDrizzleError` with `code`, `status`, and structured metadata.

### Official plugins

The first plugins shipped as separate scoped packages (merged into `better-drizzle` in 0.2.0):

- `@better-drizzle/timestamps`
- `@better-drizzle/soft-delete`
