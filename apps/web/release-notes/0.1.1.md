Adds batch updates with `updateEach` and scoped metadata with `$withContext()`. `@better-drizzle/timestamps@0.1.1` and `@better-drizzle/soft-delete@0.1.1` were released with it.

### Features

- **`updateEach`.** Updates many rows with different values in one `UPDATE ... SET column = CASE ... END` statement. Takes `by`, `data`, `update`, an optional `where`, optional scalar `select`, and `onEmpty`, and rejects duplicate `by` values. ([#12](https://github.com/almeidazs/better-drizzle/pull/12))
- **`$withContext(meta)`.** Returns a client that merges default `meta` into every operation, raw SQL call, and transaction lifecycle payload. ([`68f3f9a`](https://github.com/almeidazs/better-drizzle/commit/68f3f9a))

### Packaging

- `engines.node` is `>=18`. ([#13](https://github.com/almeidazs/better-drizzle/pull/13))
- The package is built with `tsc`, and the `drizzle-orm` peer range starts at `0.30.0`. ([`bb76ca6`](https://github.com/almeidazs/better-drizzle/commit/bb76ca6))
